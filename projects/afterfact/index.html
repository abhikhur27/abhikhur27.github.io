History with a useful answer attached

The SQLite journal accepts identical repeated events without adding duplicates and rolls back a batch if an existing event ID changes meaning. Replay respects both effective time and knowledge time, including corrections and deletions.

An exact assignment solver covers as much job priority as possible, then minimizes travel cost. Skills, availability, and deadlines are hard constraints. The explanation removes changed facts until every retained correction is needed to reproduce the new result, with source event IDs attached.

Keep the scope honest

This is a small-case investigation tool: at most 10 resources, 32 active jobs, and 12 changed facts per explanation. The result is deletion-1-minimal, not guaranteed to be the smallest possible set. It explains this model's decision, not real-world causality. Travel costs are inputs; there is no routing service or live dispatch.

Independent software project built with synthetic examples. No Palantir SDK or client data is used.
