# Return Window Tribunal

Return Window Tribunal is a browser game about handling six fictional return requests after a hardware launch.

## Core Idea

Each case has three choices. Each choice changes four hand-set game scores:

- customer trust
- fraud risk
- support load
- cost control

The game keeps a log of your decisions and counts exceptions and denials. All six cases and their score changes stay fixed, so you can compare different runs.

## Limits

The scores are made up for this game. They do not predict customer behavior, fraud, or financial results, and the examples are not legal advice about real return policies.
