# Small homepage additions

These are owner-requested additions, not a new visual direction. Keep the 800px reading column, original photo, near-black `#111110`, bone `#ecece6`, muted green `#a0c79a`, and existing Space Grotesk / IBM Plex Mono pairing. Use the existing 8/16/24/40/64px rhythm, square edges, and no shadows or glow.

## The record

The year is one continuous spiral, with one radial notch per real GitHub contribution day. A notch's length increases logarithmically with the day's count; this keeps the busiest days legible without erasing the quieter ones. Dates progress from the center toward the edge. The record does not spin or animate while someone reads it. Pointer inspection and a native date slider reveal exact dates and counts; keyboard navigation works without motion. The source link and refresh date remain visible. Failed data loads show the GitHub link instead of a fabricated empty chart.

## Portrait

Clicking the existing photograph is an opt-in joke. A single click spins it with a few square particles. Six quick clicks bring out two line-art boosters and launch a copy of the photograph through a clipped overlay. The original layout stays fixed. The empty spot says `now look what youve done`, with `bring me back` to restore it. Reduced motion and keyboard activation use a short fade instead. No sounds, idle loops, or automatic launches.
